Panduan Membuat Google Spreadsheet Realtime (0 Rupiah)

Ikuti langkah singkat berikut untuk menghubungkan formulir pendaftaran ini secara gratis ke Google Sheets Anda. Setiap pendaftar online akan langsung tercatat otomatis di Google Sheets.

1 Buat Google Sheets Baru

Buka Google Sheets, buat spreadsheet baru dengan nama misalnya "SPMB SMK YPT 2 Purbalingga".

2 Buka Ekstensi Apps Script

Di Google Sheets Anda, klik menu **Ekstensi** > **Apps Script**. Hapus semua kode default, lalu tempel (*paste*) kode di bawah ini: 

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  if (data.length <= 1) {
    return ContentService.createTextOutput(JSON.stringify([])).setMimeType(ContentService.MimeType.JSON);
  }
  var headers = data[0];
  var rows = data.slice(1);
  var result = rows.map(function(row) {
    var obj = {};
    headers.forEach(function(header, index) {
      obj[header] = row[index];
    });
    return obj;
  });
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var payload = JSON.parse(e.postData.contents);
  
  if (sheet.getLastRow() === 0) {
    var headers = Object.keys(payload);
    sheet.appendRow(headers);
  }
  
  var headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0];
  var row = headers.map(function(header) {
    return payload[header] !== undefined ? payload[header] : "";
  });
  
  sheet.appendRow(row);
  return ContentService.createTextOutput(JSON.stringify({ status: "success", data: payload }))
    .setMimeType(ContentService.MimeType.JSON);
}
3 Terapkan Sebagai Aplikasi Web (Deploy)
  1. Klik tombol biru Terapkan (Deploy) > Penerapan Baru (New deployment).
  2. Pilih Jenis: Aplikasi Web (Web App).
  3. Akses (Who has access): Pilih Siapa Saja (Anyone). *(Penting agar pendaftar tidak perlu login)*
  4. Klik **Terapkan (Deploy)** dan berikan izin akses Google Drive.
  5. Salin **URL Aplikasi Web** yang dihasilkan (awalan `https://script.google.com/macros/s/...`).
4 Tempelkan URL Webhook ke Sistem

Buka tab Database Spreadsheet di web ini, tempelkan URL tersebut ke dalam kolom **Google Apps Script Webhook URL**, lalu klik **Simpan & Hubungkan**. Seluruh pendaftar akan otomatis masuk ke Google Sheets secara realtime!
